# Nonhuman Bootstrap Constraints

Status: `PASS_3_DESIGN_PRESSURE / NOT_IMPLEMENTATION_CANON`

This addendum records constraints introduced by the nonhuman communication evidence review. It supplements `BOOTSTRAP_PROTOCOL.md` for Pass 3 so the cross-species changes remain independently reviewable before later synthesis.

## 1. Generalize the interaction subject without abandoning the first experiment

The original engineering target — two agents with zero shared symbolic language in a shared observable environment — remains a valuable controlled experiment.

The broader theory should not assume all communication is dyadic. A more general subject is:

> `two or more coupled adaptive systems with partially overlapping observables and influence surfaces`

This accommodates:

- direct dyadic exchange;
- chorusing/overlapping multi-party interaction;
- persistent chemical trails;
- collectively reinforced environmental signals;
- signal media that are also sensory media;
- delayed/asynchronous reception.

The two-agent experiment remains the first falsifiable slice; the generalized wording prevents the slice from becoming ontology canon.

## 2. Replace one binary signalhood variable with competing function hypotheses

A recurring pattern should not be forced into `signal` versus `not signal` too early.

Candidate function hypotheses may include:

- communicative social signal;
- active sensing/probing;
- camouflage;
- defense;
- self-regulation;
- locomotor side effect;
- environmental modification;
- mixed-use behavior;
- accidental correlation;
- unknown.

Evidence should bind:

`pattern + physical medium + producer/history + audience/receiver + context + response + alternatives`.

Cephalopod body patterning and electric-fish discharges are canonical controls because the same physical machinery participates in communication and noncommunication.

## 3. Physical-layer/channel discovery precedes semantic tokenization

Candidate channels include:

- acoustic pressure;
- visible motion/color/texture;
- polarization;
- electric fields;
- chemical gradients;
- substrate-borne vibration;
- touch;
- persistent environmental modification.

The bootstrap must be able to fail at the channel-discovery layer:

- `NO_SHARED_DETECTABLE_CHANNEL`;
- `CHANNEL_PRESENT_BUT_RECEIVER_MODALITY_UNAVAILABLE`;
- `CHANNEL_CANDIDATE_FUNCTION_UNRESOLVED`;
- `CHANNEL_PREPROCESSOR_SUBSIDY_DETECTED`.

A downstream semantic failure should not hide a more basic sensory/channel mismatch.

## 4. Do not require a discrete message boundary

Animal systems contain:

- continuous geometric/timing parameters;
- overlapping vocal exchanges;
- fields that decay gradually;
- signals reinforced by many producers;
- multi-timescale combinations;
- transient modulations riding a continuous carrier.

The bootstrap representation should therefore allow candidate semantic evidence over arbitrary temporal/spatial support rather than requiring `message_id -> token sequence` as the universal input shape.

## 5. Perceptual relativity is part of grounding

For any proposed grounded variable record separately:

- `EVALUATOR_PHYSICAL_VARIABLE`;
- `SENDER_AVAILABLE_VARIABLE`;
- `RECEIVER_AVAILABLE_VARIABLE`;
- `MEDIATOR_TRANSFORM`;
- `LEARNED_CROSS_SYSTEM_INVARIANT`.

Honeybee route distance is a canonical pressure case because the dance's distance component reflects bee optic-flow odometry rather than a simple human metric-distance primitive.

A bridge that maps both parties directly onto evaluator meters through privileged preprocessing has not shown that either party grounded `distance` in the same way.

## 6. Reference is a family of tested relations

Do not use a universal internal `REFERENT` label as the explanation for all externally oriented signals.

Keep separate tested relations such as:

- `EXTERNAL_EVENT_CLASS_ASSOCIATION`;
- `DISPLACED_ROUTE_VECTOR`;
- `CALLER_IDENTITY`;
- `ADDRESSEE_IDENTITY`;
- `SOCIAL_UNIT_OR_CLAN_IDENTITY`;
- `RESOURCE_LOCATION`;
- `CONTEXT_PREDICTIVE_INFORMATION`;
- `FUNCTIONAL_GOAL_OUTCOME`.

The mediator may later discover useful abstraction across these relations; the common interface should not provide that abstraction in advance.

## 7. Combination has four evidence levels

Record:

1. `FORM_COMBINATION` — physical units/features co-occur or sequence systematically;
2. `RECEIVER_COMBINATION_SENSITIVITY` — receivers discriminate combined form/order;
3. `PREDICTABLE_FUNCTION_COMBINATION` — component changes produce predictable bounded functional changes;
4. `COMPOSITIONAL_SEMANTIC_GENERALIZATION` — combined mappings transfer systematically to novel combinations/contexts.

Do not call level 1 or 2 `syntax` in the project certificate merely because the source paper uses a comparative linguistic analogy.

## 8. Intentionality is evidence, not an admission requirement

Where production shows audience sensitivity, response waiting, persistence, elaboration, or modality choice, record these as evidence supporting goal-directed communication.

Do not require equivalent intentionality evidence for systems such as honeybee dance or pheromone recruitment before recognizing communicative function.

A generic communication detector that requires human-like intentionality would erase established nonhuman channels.

## 9. Social-learning provenance is multidimensional

A bridge/convention record should distinguish:

- biologically constrained signal repertoire;
- individual learning;
- social learning;
- vocal/motor imitation;
- local group convention;
- population/clan convention;
- intergenerational/cohort transmission;
- online negotiated convention during the current bootstrap.

These provenance axes matter because two similar-looking forms can have very different recoverability and transfer properties.

## 10. Environmental persistence changes provenance

For persistent chemical or environmental signals, provenance may be:

- many-to-one;
- one-to-many;
- many-to-many;
- temporally decayed;
- no longer attributable to a present emitter.

The evaluator must not fabricate a clean sender identity where the natural signal lacks one.

## 11. Communication structure may be recoverable while semantics remain unresolved

Required intermediate states should include:

- `CHANNEL_DETECTED`;
- `SIGNAL_STRUCTURE_DETECTED`;
- `RECEIVER_DISCRIMINATION_DETECTED`;
- `COMMUNICATIVE_FUNCTION_SUPPORTED`;
- `REFERENCE_LIKE_RELATION_SUPPORTED`;
- `COMBINATORIAL_STRUCTURE_SUPPORTED`;
- `SEMANTICS_UNRESOLVED`;
- `SCOPED_SEMANTIC_MAPPING_SUPPORTED`.

Sperm-whale coda research is a canonical example: strong structure/context/combinatorial evidence should not be promoted into translated semantics without appropriate behavioral interventions.

## 12. Revised R0.5 audit subject

Pass 3 recommends extending the audit subject toward:

`(participants_or_processes, interaction_surface, candidate_channel_family, target_claim_family, admissible_strategy_family, budget, mediation_trust_partition, perceptual_variable_partition, provenance_topology)`

This is deliberately ugly. The complexity is evidence that `two agents + shared world + messages` hides assumptions that must be declared if the project is to claim universality.

A production architecture may later compress this descriptor after experiments show which dimensions are unnecessary.

## 13. New failure outcomes

Add where applicable:

- `STRUCTURE_WITHOUT_SEMANTIC_GROUNDING`;
- `CONTEXT_ASSOCIATION_ONLY`;
- `CLASSIFIER_DECODABLE_BUT_RECEIVER_MEANING_UNRESOLVED`;
- `INDIVIDUAL_IDENTITY_CUE_WITHOUT_ADDRESS_LABEL`;
- `ADDRESSING_SUPPORTED_MECHANISM_UNRESOLVED`;
- `COMBINATORIAL_FORM_WITHOUT_COMPOSITIONAL_MEANING`;
- `INTENTIONALITY_UNRESOLVED_NOT_REQUIRED`;
- `COLLECTIVE_PROVENANCE_ONLY`;
- `PERSISTENT_ENVIRONMENTAL_SIGNAL`;
- `EVALUATOR_VARIABLE_NOT_SHARED_PERCEPTUAL_VARIABLE`;
- `NOT_APPLICABLE_TO_OBSERVED_COMMUNICATION_SYSTEM`.

## 14. Revised thesis pressure

The most defensible generalized thesis after all three evidence passes is:

> Given initially unaligned adaptive systems with some physically available coupling, can a mediator discover which patterns function communicatively, determine which distinctions are identifiable and attributable to participant interaction rather than mediation subsidy, stabilize or recover grounded conventions, and recursively expand the bridge while preserving uncertainty, competing function hypotheses, non-equivalence, and not-applicable outcomes?

This does not prove that every communicator is translatable. It makes the conditions for failure explicit.
