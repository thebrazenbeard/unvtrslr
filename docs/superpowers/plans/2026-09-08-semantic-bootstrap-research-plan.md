# Semantic Bootstrap Research Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Strengthen UNVTRSLR's semantic-bootstrap thesis through three evidence-bound research passes—human verbal language, human nonverbal/signed communication, and nonhuman communication—while preserving falsifiability, provenance, and scoped claims.

**Architecture:** Work on `research/semantic-bootstrap-human-to-nonhuman-20260907` from the current R1/R2 baseline. Each pass produces an independently inspectable research checkpoint that updates a dedicated evidence review plus the shared bootstrap/control/claims/reference surfaces only where the evidence warrants it. A final synthesis is permitted only if cross-pass findings require a common-ground lower bound, R0.5 identifiability gate, first-100 dependency changes, or R1/R2 corrections.

**Tech Stack:** Markdown research corpus, Git/GitHub, peer-reviewed literature search, Chat Communication Bus coordination.

**Spec:** `docs/superpowers/specs/2026-09-07-semantic-bootstrap-research-design.md`

## Global Constraints

- Preserve `FIRST_100_CHALLENGES.md` as semantic challenges, not asserted universal words.
- Signed languages are full human languages and must not be collapsed into generic nonverbal behavior.
- Nonhuman communication is classified vocal/non-vocal unless evidence independently warrants stronger linguistic terminology.
- Separate `OBSERVED_SOURCE`, `SUPPORTED_PRIOR_WORK`, `PROJECT_HYPOTHESIS`, `INFERENCE`, `CHALLENGE`, and `UNKNOWN`.
- Distinguish discovered correspondence, negotiated convention, adapted convention, inferred equivalence, and evaluator-defined relation.
- Treat `shared observable environment` as a hypothesis-bearing interaction surface, not proof of sufficient common ground.
- No implementation, deployment, METI/transmission, autonomous-contact, or merge effect is authorized by this plan.
- All non-PR coordination for One/Four/Nine/Thirteen stays on `thebrazenbeard/chat-communication-bus`.
