# UNVTRSLR unknown-language bootstrap: executable research slice

**2026-10-27. Claim ceiling: synthetic, experimenter-scaffolded operational interaction; no verified unknown-intelligence contact or human/alien semantics.** Implements a further R0.5/Phase 1/Phase 2 step toward [mission issue #48](https://github.com/thebrazenbeard/unvtrslr/issues/48), not a universal translator claim. This is subsequent to merged `main@1e32079e3c0dc12650b0232fe729bb3741497912` (PR #49).

## Actual executable capabilities

- `src/unvtrslr/signal_discovery.py`: bounded **raw unsegmented multichannel** sampled streams (32–8192 frames, 1–8 channels) with no supplied event start/stop IDs, utterances, vocabulary or speaker meaning. Median/MAD-calibrated adaptive event segmentation, signed channel-pattern motif discovery, recurrence counts and periodicity nuisance warning. A recurrent pattern **never automatically earns intentional communication or semantic status**.
- `src/unvtrslr/contact_negotiation.py`: explicit `PartnerPort` (`observe(scene) -> continuous 2-channel response`, `offer(scene, proposed_waveform)`, `outcome(scene, proposed_waveform) -> numeric environmental feedback`). The learner sees **neither** partner's private coding, sensor-axis rule, mode, nor evaluator truth; it proactively varies two observed sensor dimensions, discovers opaque waveform motifs from each unsegmented response, tests which dimension explains their variation, proposes its own different arbitrary waveform conventions, checks training-context feedback, repeats an unconfirmed proposal once, and tests success on separate numeric held-out situations. No English or prewritten bilingual dictionary is used.
- `runs/contact_20261027/run.py` contains a **separate evaluator-only synthetic partner** with private rule and randomized observed waveform/channel/timing; the learner only receives the `PartnerPort` surface. Four private seeds test 3 raw-stream detection scenarios and 9 interactive partner scenarios each. Original operator supplies the simulator, scene representation, and measurable scalar payoff; this is NOT an independent real or adversarial external intelligence.
- `tests/test_contact_discovery_negotiation.py` covers reproducibility, false positives, null behavior, periodic nuisance, missing signal, unstable or unrelated emissions, XOR/non-separable underlying reference, non-adapting participants, delayed agreement/repair, private-rule change on heldout contexts, partner replacement, scene and numeric poisoning, unknown codebook, and message/intent claim limits.

## Frozen experimental observations

Local Lappy evaluation across four seeds yielded **12/12** expected signal-discovery control classifications and **36/36** expected interaction scenarios. All four responsive simulated partners acquired a reciprocal operational convention on heldout physical-context values with reported environmental outcome `0.9`; the learner inferred which sensor axis covaried with emitted candidate signals, without that axis being supplied as input. Cases that returned no signal, stable but non-discriminating behavior, random and XOR-correlated behavior, a constant-reward spoof, nonadaptive partners, and partners changing their rule on holdout did **not** receive successful convention status. Slow-learning participants required **24 offers instead of 12**, demonstrating a bounded repeat/correction attempt. The success metric is deliberately an evaluator-controlled synthetic environmental measurement, not semantic interpretation.

Reproduce using `python runs/contact_20261027/run.py --out <new-path>.json` with `PYTHONPATH=src;.` under Windows. The committed report `research/CONTACT_DISCOVERY_RECEIPTS_20261027.json` includes every control case, seed, interaction limits and explicit `real_unknown_partner_contacted=false`. Avoid writing another report to an existing path; the tool refuses overwrite. Test with `python -m pytest -q tests/test_contact_discovery_negotiation.py`.

## Critical scientific and deployment limits

1. **No inference of intent or signalhood:** a meaningful-looking change could be a reflex, optical artifact, machine cycle or physical coupling. Segmentation does not assign communicative function. Periodicity alone is specifically marked uninterpreted.
2. **No genuinely autonomous discovery of sensory affordances:** we supply finite sampled channels, expected amplitude range, two accessible numeric environmental dimensions, fixed scene intervention choices, recognizable bounded pulse style, and known per-query capture windows. The raw survey has no event delimiters, but active probe interfaces still contain experimenter-defined trial captures.
3. **No established general semantics:** an arbitrary learned symbol corresponds to one tested operational sensor partition. The coordination feedback is an engineered **reward/confirmation surface**, not a universality-proof meaning oracle. The outcome could equally arise from artificial conditioning.
4. **No independently unknown intelligence:** the partner is an evaluator-specified Python class with private randomized rule. It is **unknown to the learner instance**, not independently unknown to humanity; no real external participant was observed or contacted.
5. **No security isolation:** the evaluator and learning code reside in the same repository and operating-system principal. Python Protocol type checking is not an OS sandbox, nor do bounded inputs guard against malicious callback side effects or hangs. Run only explicitly trusted, authorized external partner adapters; a practical connector must impose permissions, timeouts, energy/output limits and consent.
6. **No cross-partner magic:** tests deliberately confirm that a fresh partner without prior offers does not already share the invented convention. It can acquire one only through fresh interaction. No linguistic/vocabulary claims follow.
7. The original challenge explicitly includes potentially incompatible ontology, modalities and even absence of distinct agents. The present binary two-sensor simulation does not address those conditions. **Do not rewrite these constraints as solved.**

## Next hostile gates

- Substitute a genuine independently implemented partner on another machine/account, with no shared code, simulator truth or synchronized IDs; pre-register partner inputs and evaluator-heldout trials, show a prohibited canary cannot be read.
- Discover **which** raw physical channel and temporal scale to use from multiple competing sensors without predefined response channels or per-query message captures; test time-drift, adversarial periodic sources and continuously overlapping signals.
- Validate bidirectional correction, explicit refusal/withdrawal and convergence without a prearranged engineered payoff oracle. Include non-equivalent concepts and goal conflict, with negative controls that simulate cooperation.
- Measure causal effect of signaling versus suppression, randomized partner swapping and newly generated worlds. Compare information-gain probe selection versus random/uninformed protocols.
- Only then consider authorized real-world observations/actuators and any contact experiment. This repository does **not** assert alien contact, evidence of alien existence, or a way to identify arbitrary unknown intelligences from noise.
